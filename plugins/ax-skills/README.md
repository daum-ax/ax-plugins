# ax-skills

비개발자를 위한 Claude Code 도구 모음입니다. 혼자 바이브코딩하고 혼자 배포하는 사람이
**처음 준비 → 커밋 → GitHub에 올리기 → 버전 남기기**까지 막히지 않도록 돕고, 결과는 어려운
말 없이 알려줍니다.

한국어 사용자를 대상으로 만들었습니다. 베타 버전이에요.

## 설치

```
/plugin marketplace add daum-ax/ax-plugins
/plugin install ax-skills@ax-plugins
```

자세한 절차와 zip 수동 설치 방법은 [`INSTALL.md`](INSTALL.md) 를 봐주세요.

## 무엇이 들어 있나요

**핵심 — 이 순서로 씁니다**

- `welcome` — git·gh 설치 확인, 내 이름 등록, GitHub 로그인까지 순서대로. 빠진 것만 채웁니다
- `github-login` — GitHub 연결이 안 되거나 비밀번호를 안 받아줄 때
- `commit` — 알아서 메시지를 만들어 커밋 ("커밋해줘")
- `push` — 커밋한 작업을 GitHub에 올리기 ("올려줘"). 저장소가 아직 없으면 비공개 저장소를
  새로 만들어 연결합니다
- `release` — 지금 상태를 `v1`, `v2` … 버전으로 남기기 ("버전 남겨줘"). 배포와 되돌아가기의
  기준점이 됩니다

**안전망**

- `status` — "지금 무슨 상태예요?" 읽기 전용 진단. 뭔가 꼬였을 때 먼저

여럿이 함께 쓰는 저장소를 위한 기능(PR·pull·충돌 정리)은 이 도구 모음에 들어 있지 않습니다.
그런 상태를 만나면 도구가 멈추고, 지금 상태를 그대로 두고 누구에게 물으면 되는지 알려줍니다.

### 알려진 한계

- 한 저장소에 서비스가 여럿 들어 있으면(모노레포) `release` 의 `v1`, `v2` … 번호를 서비스끼리
  나눠 쓰게 됩니다. 지금은 저장소 하나에 서비스 하나를 가정합니다.

## 설계 원칙

- **되돌릴 수 없는 일은 먼저 물어본다.** 모든 흐름은 중간에 멈춰도 이어서 할 수 있는
  상태로만 남깁니다.
- **강제 덮어쓰기는 하지 않는다.** `push --force`, `reset --hard`, 이미 올린 이력 고치기는
  어떤 상황에서도 쓰지 않습니다.
- **기술 선택은 알아서, 내용 선택은 사람이.** 버전 번호나 저장소 공개 여부는 도구가
  정하고, 저장소 이름과 버전 설명은 반드시 사용자가 확인합니다.
- **개발자가 곁에 없다고 가정합니다.** 막혔을 때는 "개발자에게 맡기세요" 대신, 지금 상태를
  그대로 두고 누구에게 물어보면 되는지를 알려줍니다.
- **결과는 쉬운 순서로.** 한 줄 결론 → 쉬운 설명 → 기술 상세는 요청할 때만.
