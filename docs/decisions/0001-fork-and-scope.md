# 0001 — 분기와 범위 (2026-09-08)

**결정.** 특정 팀용으로 먼저 만들어 쓰던 플러그인(`jay-skills`)에서 갈라져 나와, 회사 안
비개발 직군 누구나 쓰는 범용 플러그인 `ax-skills` 를 이 저장소에서 따로 개발·배포한다.

**왜 새 저장소인가.** marketplace 로 등록되면 저장소 전체가 사용자 컴퓨터에 clone 된다.
원래 플러그인은 내부 결정 기록이 많은 큰 저장소 안에 있어 배포용 미러를 따로 두고
동기화해야 했다. 여기서는 저장소 자체를 공개 가능한 내용만으로 구성해 **개발처 = 배포처**로
단순화한다. 그 대신 검증(구조 validate·금지 문자열)은 `scripts/check.sh` 와 CI 가 맡는다.

**분기 시점 조사 수치.** 원본 20개 파일 중 팀 고유 문구 2곳, 사람 이름 2곳, 옛 튜토리얼
예시 16곳, 옛 이름 154곳. 기술스택 종속은 dev-up 한 스킬(0002 참고)과 잠금 파일 목록 한
줄. 즉 내용은 이미 대부분 범용이었고, 작업의 본질은 "새 집 + 이름표 + dev-up 골격 분리".

**두 줄기 병행.** 원본 플러그인은 그 팀용으로 계속 유지된다. 범용 개선은 여기 먼저 넣고
사람이 문장을 옮겨 적는다. 자동 동기화·byte 비교는 하지 않는다 — 갈라짐이 의도다. 장부는
`CHANGELOG.md` 의 "자매 반영" 열 하나.

**공개 범위.** 사내용. 라이선스 UNLICENSED. 문의처는 역할명("저장소 관리자"). 버전은
0.1.0 부터 새로 — 새 이름은 Claude Code 에 새 플러그인이고, dev-up 축소는 원본 대비 행동
변경이라 이어 세는 것이 오히려 오해를 준다.
