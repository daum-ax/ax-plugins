# 0002 — dev-up 을 스택 무관으로 (2026-09-08)

**문제.** 원본 dev-up 은 328줄 중 약 절반이 Node·Volta·nvm·launch.json 절차였다. 범용
플러그인의 사용자는 Node 웹앱뿐 아니라 Python 스크립트, HTML 한 장, 스프레드시트 매크로 등
무엇이든 만들 수 있다. 특정 스택 절차가 본문에 있으면 (a) 다른 스택에서 오작동하거나
(b) 스택 무관 원칙과 어긋나는 문장을 매번 읽게 된다.

**결정.** 본문에는 스택 무관 골격만 둔다 — "프로젝트가 스스로 적어 둔 명령만 실행" 원칙,
`.claude/launch.json` 정본 규칙, `.env` 처리, **포트 점유 시 정체를 보여주고 동의받는
3분류**, 접속 확인, 번역표의 범용 행, Rules. 스택별 절차는 `references/<스택>.md` 레시피로
분리하고, Step 1 이 선언 파일(`package.json` 등)을 보고 어느 레시피를 펼칠지 정한다.
지금은 `node-volta.md` 하나.

**레시피가 없는 스택.** README 에 적힌 명령만 그대로 쓴다. README 가 도구를 요구하는데
설치법이 없으면 지어내지 않고 멈춰서 누구에게 물을지 알려준다. `index.html` 만 있는 정적
페이지는 "브라우저로 열어드릴까요?" 한 번 묻고 `open` — 파일 열기는 절차를 지어내는 일이
아니라고 판단했다.

**유지한 것.** 잠금 파일 목록(fix-conflict·git-collab §6)은 안전 목록이라 남기고
`poetry.lock`·`Pipfile.lock` 을 더해 일반형으로 읽히게 했다. Volta 경유 규칙(launch.json 에
명령 이름만 적으면 다른 Node 가 잡혀 서버가 죽는 실측)은 레시피 R5 로 옮겼고, 본문은
"레시피에 경유 규칙이 있으면 따른다"로 가리킨다.

**결과.** 본문 328 → 256줄, 레시피 146줄. 새 스택 지원 = 레시피 파일 1개 + Step 1 표 한 줄.
